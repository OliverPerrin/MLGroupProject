<h1 align="center">ML Group Project</h1>

<p align="center">A university group project on classifying driving behaviour from phone motion sensors.</p>

---

### What is here

[MLProject.ipynb](MLProject.ipynb) loads the [Driving Behavior dataset](https://www.kaggle.com/datasets/outofskills/driving-behavior) from Kaggle. The inputs are accelerometer and gyroscope readings on three axes, and the label is the driving style.

The notebook currently covers data loading only. Modelling was not added to this repository.
